# COMP1238 - Midterm Notes

## Week 1 - History
- One writing system can be used by many languages
- Cuneiform is one of the earliest writing systems
- The Epic of Gilgamesh is one of the oldest known written stories

## Week 2 - Bits and Bytes
- A bit is a single 0 or 1
- A byte is 8 bits and can represent 256 different values

## Week 3 - Character Encoding
- ASCII uses 7 bits per character and only covers basic English characters
- Unicode assigns a number to characters from nearly every writing system

## Week 4 - Text Files and Formats
- Plain text files store only characters, with no formatting
- A file extension hints at the format but doesn't change the contents

## Week 5 - Markdown and Version Control
- Markdown is a simple syntax that turns plain text into formatted pages
- Git tracks the history of changes, and each commit is a saved snapshot
